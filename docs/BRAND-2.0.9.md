# 灵感边框 2.0.9：品牌与界面对齐

2026-10-27。落实已确认名称“灵感边框”、新的相框 Logo，以及设置页和编辑控件对齐优化。本轮不改变照片处理和排版数据结构。

## 检查与修改清单

| 步骤 | 问题 | 处理 |
|---|---|---|
| 1. 名称 | 桌面、启动、旧工具页与导出通知仍有旧品牌 | 更新为灵感边框；包名、签名和数据库保持原有身份 |
| 2. 图标 | 旧图标细节过多，新稿在安卓桌面中主体偏满 | 使用开口相框与亮色角标；按安卓自适应规范重新包装，主体约 48 × 47 dp，居中放入 108 dp 图层 |
| 3. 外形适配 | 不能只按设计源图判断圆形/方形效果 | 使用真实前景资源和 Android 的图层扩展比例，检查圆形、圆角方形、方形及单色；保留背景、前景与主题层 |
| 4. 设置页 Logo | 品牌展示块偏大 | 显示尺寸从 56 dp 调整为 48 dp，圆角同比收紧 |
| 5. 设置项垂直位置 | 最小行高加在外层，内容却靠上摆放 | 内容行自己承担最小 64 dp 高度，统一垂直居中；高度随大字体增长 |
| 6. 文字基线 | 标题与右侧数值字号不同，按中心摆放时基线错位 | 同行文字按第一条基线对齐；长文字时标题和值上下排列 |
| 7. 左侧网格 | 分组标题、列表文字与分割线使用不同边距 | 统一页面 16 dp、卡片内 16 dp 网格；分组标题、行标题与分割线共享起点 |
| 8. 右侧网格 | 有箭头和无箭头行的数值终点不同 | 数值共用末端列；所有普通行预留同宽配件区，箭头居中 |
| 9. 开关 | 与文字列表的内距和行高不同 | 使用相同列表行；整行可切换，保留系统开关语义 |
| 10. 记录文案 | “草稿与已完成任务 / 最近5条”容易误解为合计5条 | 分为“草稿 / 最近5份”和“导出记录 / 最近5条”，实际保留规则不变 |
| 11. 顶部导航 | 返回与标题缺少平衡的留白 | 标题居中，左右保留相同导航宽度，保持至少48 dp返回触控区 |
| 12. 编辑面板 | 面板标题与正文控制列相差4 dp，滑杆数值基线不齐 | 编辑器、作品库、导出标题统一16 dp内距；滑杆标题和值按基线对齐 |
| 13. 中英文与大字体 | 短标签能放下不代表所有语言/字号稳定 | 布局与交互检查覆盖320、360、402 dp以及最高2倍字体，临时英文检查后恢复原应用语言 |

图标依据：[Android 自适应图标](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)。图标层为108 dp，官方建议主体48–66 dp；本轮采用约48 dp，避免占满视觉区域。按25%图层扩展计算，圆形边界还有约6.87%图标边长的径向余量；见 安全区记录（`artifacts/branding-2.0.9/safety.txt`）。

界面参考：[Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。采用其中的共同对齐、视觉层级和材质分层原则；这是安卓自有实现，导航保留玻璃材质，列表内容使用稳定底色。

## 图标交付

图形由 Creative Production / ImageGen 生成，安卓前景和单色层从同一图形导出，不使用竞品素材。先生成的透明边缘稿存在杂点，已替换为干净的正式图形。实际安装资源按用户反馈缩小，并非直接把整张设计图当作启动图标。

- `drawable-nodpi/brand_mark.png`：带安全区的彩色前景。
- `drawable-nodpi/brand_monochrome.png`：相同位置的单色主题层。
- `mipmap-anydpi-v26/ic_launcher.xml`：背景和前景。
- `mipmap-anydpi-v33/ic_launcher.xml`：额外包含单色层。
- 通知使用单独的透明单色图形，不能将彩色整块图标直接当作通知小图标。
- 512 px 商店图标（`artifacts/branding-2.0.9/play-icon-512.png`）：未预先嵌入圆形遮罩。

不同外形与大小的图标检查（`artifacts/branding-2.0.9/android-masks.png`）
