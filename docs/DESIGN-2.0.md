# 原生编辑器视觉与交互规范

本轮根据 Apple Liquid Glass 的设计原则改造 Android 原生界面；不是调用 iOS 私有组件，也不打包 Apple 字体或系统图标。

## 依据

- [Apple：Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：玻璃用于导航与控制层，图片区保持清晰；长文字和复杂面板使用更稳定的底色。
- [Apple：Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)：操作按用途分组，主要操作具有明确优先级，控制数量保持克制。
- [Apple：Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)：考虑内容与浮动控件的关系，并适配系统辅助功能。
- [Apple：Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：明暗外观、文字缩放、运动和透明度偏好纳入设计。

## 已实现的规则

- 中性灰画布、照片为主体；绿色仅强调选中状态和导出。
- 顶部作品库、撤销/重做、导出分组；底部七组工具，单独提供图下正文。小屏和大字体时横向滚动，保持点击区域；文字图隐藏无效的照片参数与滤镜。
- 透明工具栏和更稳实的参数面板分层，统一连续圆角、边缘高光、柔和阴影和按压反馈。
- Android 12 使用系统模糊；Android 13+ 加入 AGSL 透镜折射。由 Backdrop 1.0.0 实现原生采样和效果。
- HDR 照片独立于玻璃采样层，避免将高动态范围图像重复采样或重新合成；玻璃效果只作用于界面。
- 明暗外观跟随系统；作品库提供“降低透明度”，系统动画缩放由 Compose 处理。
- 图标控件至少 48 dp 点击区域；常规正文 15–17 sp，最小辅助标签 11 sp，支持系统字体缩放。
- 移除照片使用缩略图右上角关闭按钮，支持撤销；添加照片始终固定在缩略图栏右侧。
- 水印空输入只进入临时编辑，实际有内容后才创建图层；清空会移除，完成编辑退出输入状态。已有项显示内容和删除入口。
- 正文与画面水印分别编辑；正文先测量再扩展画布，清空后没有占位区。对齐、字体和颜色作用于预览及导出。
- 滤镜按基础、胶片、电影、人像、黑白分组，使用真实照片缩略图和强度滑杆。
- 普通预览单指滑动不会修改照片；图层拖动按实际画面坐标命中，辅助线仅在拖动时显示。
- 导出设置可滚动，保存动作固定在面板底部；打开即完整展开，避免主要操作隐藏在屏幕外。
- 键盘打开时隐藏缩略图和底部工具栏，保留照片预览与当前输入面板。
- 用按钮、图标、选中状态和预览传达操作，避免在工作区堆叠说明文字。

## 验证方法与限制

使用官方 Compose Screenshot 工具在 Mac 上渲染浅色、深色、水印编辑、360 dp/1.5 倍字体四种布局，无需模拟器。该工具的检查模式使用玻璃降级材质，主要检查排版和字体；真实的 GPU 折射另在 Redmi / Android 16 上检查。

真机已检查主界面、水印输入、软键盘、HDR 预览、滤镜和照片删除入口。横屏、TalkBack 全流程和不同厂商系统还需要单独验收；不能以当前截图代表所有设备。

## 2.0.2 调整

- 样式使用一行文字选择按钮，明确展示加粗、描边、阴影、底色和锁定。恢复默认、完成、删除、清空与恢复原图也使用文字动作，保留常见的导航图标。
- 输入标签固定在输入框上方，保留输入法组合与光标；编辑期间不按有值/无值重新排序字段。
- 几何量显示排版像素，行距显示倍数，段间距显示字高；透明度和强度继续显示百分比。
- 兼容分享是有固定编码规则的尺寸预设，自定义提供完整参数。切图预览展示编号和逐块尺寸。

## 2.0.4 表单与选择流程

- 原生相册共用编辑器的玻璃材质，照片网格作为采样来源；相册页自持背景层，不采样被遮住的编辑器。顶部取消/标题/更多，独立相册胶囊，底部数量/清空/添加。照片只读，玻璃不进入输出。
- 相册窗口的状态栏与导航栏图标随主题变化；固定导航与确认控件测量后为网格预留空间。
- 表单标签在输入行上方；勾选框、输入框、清空/恢复按钮在同一行居中。文字动作各 48 dp，输入使用稳定圆角填充、细边框与焦点色。
- 单行输入键盘提供完成；多行输入保留换行和中文组合。滑杆行至少 48 dp 并提供名称与当前值语义。
- 新作品及缺失段间距字段均默认 .5 字高、行距 1.3；显式保存的 0 不改写。文字、边框和调色面板顶部统一恢复默认，恢复仅作用于当前工具。
- 导出面板只采用一份高度预算；设置区滚动，保存区固定并保留底部安全区。
- 作品库首先显示草稿；新作品/文字图保持可见，预设管理进入更多。显示完成按钮，空分组隐藏；删除记录要说明对象，已保存图片保留。
- 文案统一恢复默认、清空、移除照片、删除记录；取消选择、恢复、完成使用文字。仅在权限、失败或 HDR/SDR 模式改变时说明必要原因。
