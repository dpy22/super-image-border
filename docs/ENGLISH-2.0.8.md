## 新的命名方向

用户希望接近“像素蛋糕”“美图秀秀”的品牌感：顺口、有记忆点、带有图片联想；不再仅罗列功能，也避免过于文艺。

| 候选 | 方向 |
|---|---|
| 像素方糖 | 照片联想明确；方块、边框可以形成统一图形，优先推荐 |
| 咔嚓贴贴 | 活泼，容易联想到照片与贴文字、水印 |
| 像素搭搭 | 对应搭配模板、拼图与图片排版 |
| 相片吐司 | 更接近趣味食物品牌，能延伸相纸白边图形 |
| 咔嚓工坊 | 相对稳重，能容纳边框、水印和调色等功能 |

品牌名可搭配功能副标题“照片边框 · 摄影水印”。这些仍是创意候选，尚未核实商标及商店重名，不代表已可注册。
