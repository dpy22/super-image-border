# 灵感边框 2.0.11：精确调整与交互审查

2026-10-27。本轮以滑杆为起点，审查文字、画幅、边框、水印、调色、导出之间的数值和输入交互。沿用现有液态玻璃视觉、原生控件、包名与个人安装签名；不更改用户原图。

## 流程与证据

1. **进入边框调整**：当前手机截图确认，已有统一标签和单位，但数字是只读文字，没有微调或精确输入入口。修复后应能拖动、点数字输入和按加减。
本轮边框基线（`artifacts/audit-2.0.11/before/frame.png`）
2. **进入文字排版**：当前手机截图确认，文字、字体和宽度模式在同一个滚动面板。代码进一步确认自动字号与手动字号是不同模式；自动字号保持只读，不添加冲突输入。行距和段间距提供常用值，但放在数值编辑中，不给常态面板增加一排排档位。
本轮文字基线（`artifacts/audit-2.0.11/before/text.png`）
3. **调色与数值编辑**：当前手机曝光控件仅有滑杆与只读数值。新的数值输入需明确单位、范围、正负号和小数精度，并支持即时预览与取消恢复。
本轮调色基线（`artifacts/audit-2.0.11/before/adjust.png`）
4. **确认、撤销、切换工具及导出**：用行为检查验证数值提交、一次操作对应一次撤销、焦点收尾及导出尺寸；截图本身不能证明这些行为。

## 问题清单与修复

| # | 问题 / 证据 | 修复 |
|---|---|---|
| 1 | 数字只读，精确值必须靠拖动（步骤 1、3） | 点数值打开精确输入，默认选中原数字 |
| 2 | 连续浮点内部值被显示为整数，显示与设置不一致（源码） | 主动调整按显示单位取步长；输入 100 px 对应 100 px 的内部换算 |
| 3 | 缺少最小步长微调（步骤 1） | 48 dp 点击区的减/加按钮，长度 1 px、百分比 1%、行距 0.01、段间距 0.05 em |
| 4 | 长按连续调整可能拆成很多撤销（行为） | 长按重复以一组记录，松手结束；下一次操作另起一组 |
| 5 | 以数值范围或本地化字符串猜单位（源码） | 稳定参数键对应显式单位、换算比例、精度及步长 |
| 6 | 行距和段间距难以恢复常用值（步骤 2） | 输入面板提供行距 1/1.15/1.3/1.5、段间距 0/0.25/0.5/0.75/1 em |
| 7 | 同时开放按字数和字号会互相覆盖（步骤 2） | 按字数模式精确编辑字数，自动字号继续只读 |
| 8 | 输入负数时某些数字键盘没有负号（输入兼容） | 可负参数显示明确的正负切换按钮；不依赖键盘厂商布局 |
| 9 | 输入中的空值、小数点或越界值可能导致跳动（行为） | 输入草稿独立保存；仅有效值更新预览，非法值保留在输入框并阻止确认 |
| 10 | 小数精度错误和越界混淆（行为） | 按整数、小数精度、范围分别提示；不静默截断或强制夹取 |
| 11 | 取消可能保留预览中的修改（行为） | 取消、返回和外部关闭恢复原值，且不增加无效撤销记录 |
| 12 | 原作品数值可能因打开新控件被自动舍入（迁移） | 仅主动操作时采用新步长，浏览不改原值；取消保留原有小数 |
| 13 | 角度 -12.5° 加一步被整数吸附吞掉（新增边界检查） | 微调保留输入的小数，-12.5° + 1° = -11.5° |
| 14 | 水印包含手势缩放、Logo 宽度有 8 倍基准，不能统一乘照片短边（源码） | 使用真实基准换算；自动适配时单独显示适配后尺寸；素材读取失败时不阻断工具面板 |
| 15 | 锁定控件仍像可操作、范围边缘按钮无意义（行为） | 数字、滑杆、加减统一禁用；边界禁用对应方向 |
| 16 | 辅助技术读到内部比例，难以精确设置（语义） | 滑杆范围与进度使用显示单位，数值输入、加减有独立本地化名称 |
| 17 | 中英文长标签、大字体和错误内容可能挤出布局（布局） | 标签可换行、数字列保留空间；输入内容可滚动，确认和取消独立于滚动区 |
| 18 | 切换工具、撤销及恢复默认时只藏键盘、未统一结束输入（源码） | 清焦点、结束输入/撤销分组、隐藏键盘后再导航或恢复 |
| 19 | 调色强度与物理单位混淆（源码） | 曝光用 EV，基础有符号调节用 -100…+100；不透明度等明确使用百分比 |
| 20 | 导出尺寸与质量沿用不同控件规则（源码） | 自定义最长边支持直接输入和 1 px 微调；JPG 质量用整数；保留含框实际尺寸与分享档位 |
| 21 | 进程/界面重建前，AppCompat 语言缓存可能尚无活动代理（复查） | Android 13+ 直接读取系统 LocaleManager 中的应用语言；Android 12 保持兼容路径 |
