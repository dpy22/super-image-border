# 2.0.7：独立设置页与中英文

## 已实现

- 顶部增加设置入口；设置为独立页面，支持返回。通用设置、作品库记录规则与关于分组显示。
- 语言提供跟随系统、简体中文、English，默认无应用语言覆盖，跟随系统。Android 13+ 与系统的应用语言设置同步，Android 12/12L 使用 AppCompat 的兼容存储。
- 语言改变时按 Android 正常配置流程重建页面；设置页保持打开，当前作品、文字、摄影参数、滤镜键和预设不改写。
- 406 项现有文案、32 款模板名及设置/隐私文案使用标准 Android 字符串资源。编辑器、图下正文、水印、摄影参数、相册、导出、错误与通知覆盖中文/英文。
- 中文的旧滤镜/模板数据键保留，显示名称单独本地化，不破坏旧草稿或预设。
- 英文长标签和系统大字体下，工具栏按实际文字宽度滚动；参数清空/恢复动作按字体缩放。相册色彩建议横向可达，模板名称单行省略。
- 降低透明度从作品库移至设置；隐私详情在单独页面，不占编辑器空间。
- 兼容入口“1.1 旧版工具”移至设置，明确标注仅中文。旧网页尚未本地化；原生功能为主要流程。
- 当前名称及图标未改；尚未选定品牌，不把候选名字当作已定名。

技术依据：[Android 应用语言](https://developer.android.com/guide/topics/resources/app-languages)。未新增照片上传或账号依赖；应用原有包名、签名与照片路径保持稳定。

## 名称与图标方向

用户偏好：用途直接、便于搜索，不采用仅有意境的名字。

候选：照片边框与水印、边框水印、照片加框、相框与水印、一键加框。优先推荐前两项。英文功能名可考虑 Photo Frame & Watermark。

这些是方向候选，不是商标或商店名称可用性的确认，也不保证搜索排名。Google Play 允许分语言名称，标题上限 30 字符，并建议准确描述功能且具备辨识度。依据：[商店资料字段](https://support.google.com/googleplay/android-developer/answer/9859152)、[商店资料建议](https://support.google.com/googleplay/android-developer/answer/13393723)。

现有图标为绿色背景、相纸照片和两条细文字线，更偏旧图文拼接工具。建议新图标保留明确的照片框轮廓，删去小文字细节，使用一个水印角标作为识别点；同时提供 Android 自适应与单色图标。此次未直接替换品牌图形。
