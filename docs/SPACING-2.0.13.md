# 灵感边框 2.0.13：参数留白与位置

2026-10-27。本轮针对实际照片中参数区“上紧下松”的反馈修正，并开放独立的位置与排列。

## 现场审查

1. **当前作品 → 参数页：发现问题。** 本轮重新捕获手机当前应用窗口。参数区既加了上下内距，又叠加外框底边；此前只测区域不重叠，没有测可见字形到边缘的距离，因此未发现这个失衡。

修改前（`artifacts/audit-2.0.13/01-before.png`）

2. **参数 → 位置与排列：本轮新增。** 参数位置可选上、下、左、右；排列可选纵排或分栏；对齐可选左、居中、右。默认随模板，单独选择后保存在作品和预设中。换模板会重新采用模板的默认参数布局。“恢复默认”只重置布局，不清空参数字段。

3. **预览/导出：共用新布局。** 间距不再在参数区底部和外框重复相加。普通模板自动让照片间距匹配相应外框边距；自动间距上限为短边 8%，避免拍立得/宽银幕等特意加宽的外框把参数推得过远。用户仍能手动设置照片间距和侧边参数区宽度。原图不因移动参数而裁切；多图仍逐图显示自己的参数。

## 实现与兼容

- 参数按可见字形范围测量和摆放，避免字体行框中的空白造成视觉偏移；中英文、长字段、分栏分别验证。
- 只添加所需的参数区和照片间距，底边继续使用边框设定。上方布局相应匹配顶边，左右布局默认垂直居中。
- 旧版默认的 2.4% 内距迁移为自动间距；已经修改过的内距保留为手动照片间距。旧侧栏的预留宽度转换成独立参数栏宽度，避免移动到其他位置后遗留大片空白。
- 参数区尺寸、间距和栏宽仍按原图相对比例保存。像素取整只用于输出与照片位置；新增检查覆盖取整后参数区、正文的实际边界。
- 参数布局入口默认折叠，使用文字按钮；新增控件中英文适配，保持大字体可达与完整显示，不添加解释性长文案。
