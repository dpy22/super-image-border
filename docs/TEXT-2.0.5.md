# 2.0.5 正文行距与按字数排版

- 新作品、恢复文字默认和缺失行距字段的读取，统一采用 1.15 倍。已明确保存的旧行距不改写。段间距仍默认 0.5 字高。
- “按字数”保持完整的照片横向宽度，默认左右留白为 0，再用所选字体的全角中文字宽计算字号；不再用固定字号缩小文字栏。手动设置左右留白时，按扣除后的可用宽度计算。
- 字号随横向排版宽度、每行字数、字体及加粗变化，预览和导出共用测量；原始照片像素没有缩放或改写。
- 按字数模式显示“字号 … px · 自动”，暂时隐藏手动字号滑杆；切回跟随照片/固定宽度后保留此前手动字号。
- 每行字数以中文全角字为基准。英文、数字、标点和显式换行遵循正常排版，不把每一行强拉成相同字符数。居左/居中/居右/两端/分散仍独立生效。
- 原“文字内边距”拆为左右留白与上下留白，分别控制；旧按字数样式自动采用零左右留白，其他模式保留原内距。预设与草稿保存独立值。
- 字体测量和绘制使用相同的线性亚像素字宽，避免整数取整令一行无法填满。
- 自选宽高比不将字号绑定到外侧留白；单图以实际照片排版横向宽度为准，多图以整组内容宽度为准。
