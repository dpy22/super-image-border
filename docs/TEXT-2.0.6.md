# 2.0.6 按字数：标点和英文的排满规则

原来的“按字数”只调整字号，断行仍交给系统的整词和标点避头尾规则，因此中英文混排时可能提前换行，留下右侧空白。

新版在“按字数”模式：

- 按实际字宽尽量填入完整字符簇，允许在英文单词中换行，不再因整词或标点规则提前移走一段文字。
- 自动换行的非末行，通过字距补齐剩余宽度；不改变照片或拉伸字形。
- emoji、肤色修饰、旗帜、连接 emoji 和组合音调按完整字符簇保护。
- 手动换行仍建立独立段落，段落末行保留所选对齐；主动选择分散对齐时末行继续分散。
- 保存的正文保持原文；内部排版文本插入的软换行和字距不写回正文。预览、PNG/JPEG、HDR 合成共用测量与绘制。
- 其他文字宽度模式继续采用原有断行方式；不增加解释性控件。

## 本轮验证

- 7 项后台真机检查通过，0.561 秒。覆盖中文全角字、英文词内续行、括号/标点、五种对齐、段落末行、emoji/肤色/旗帜/组合音调、字号与宽度、全模板正文高度及清空。
- 中英混排正文的全尺寸预览与实际分条 PNG 导出，正文像素逐一对照一致。
- 断行宽度采用排除行尾空白的实际行宽验收；Android 的 `getLineWidth` 包含行尾换行空白，改用 `getLineMax`，依据 [Android Layout](https://developer.android.com/reference/android/text/Layout#getLineMax(int))，没有通过放宽溢出限值绕过检查。
- 首次混合测试的宽度断言误计了内部软换行的尾部空白；修正度量后全部排版检查通过。首次界面测试因手机在其他应用而未进入编辑器，没有将该步骤标为通过；最后检查在后台执行，不操作其他应用。
- 使用 App 自建色块图检查实际渲染，没有上传或复制用户原图。
