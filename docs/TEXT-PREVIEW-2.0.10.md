# 灵感边框 2.0.10：正文排版与预览清晰度

2026-10-27。针对手机当前作品中首段末尾“欲”和句号各占一行，以及编辑预览偏糊的问题。

## 根因与修改

- 原按字数排版先用 Paint 估算字距，再将带字距的完整段落交给 StaticLayout。混合中文、数字和标点在大字号下的两次度量不同，系统将已填满的行再次拆开。使用真实相同行的整形、测量和绘制结果，通过不可再拆分的行承载，保留系统字体回退与 emoji；不缩放字形、不修改原文。
- 非末行继续按实际字宽填满，英文仍可在词内换行。句末只剩关闭标点时，将前一个完整字符与标点一起留到末行，避免句号单独成行。保留原来的五种对齐、字数对应原图横向宽度、1.15 默认行距和段间距。
- 原预览清晰化等待撤销分组结束，文字输入框持有焦点时可长期停在 768 像素交互图。改为停笔 300 ms 即清晰化，与撤销分组解耦。
- SDR 在适合屏幕和放大时均在手势/输入停顿后按可见区域重新绘制，照片读取原图区域；不再只在 1.25 倍以上触发。布局变化会重新计算可见区域，避免正文高度变化后继续使用旧比例。
- 可见区域按屏幕物理像素绘制，安全预算为约 400 万像素、最长边 4096；不加载整张全尺寸成片。超出预算时仅限制预览，不更改导出尺寸。HDR 继续使用独立浮点预览，本轮未改为 HDR 区域解码，也未提高 HDR 放大时的源分辨率。

## 验证

- 新增真实首段回归，在三种字体、普通/粗体、五种画布宽度下确保预先排好的行不会再次断行，句号不单独占行。
- 保留中英混排、标点填满、字数对应字号、完整 emoji/组合字符、五种对齐、段间距、模板正文清空及全尺寸 PNG 导出的检查。
- 新增文字/滤镜保持输入分组打开时，停顿后仍与完整清晰帧一致的检查。
- 使用超过整图预览预算的长正文，加黑白单像素条纹图，验证 2560×240 可见区域的照片像素与原图逐一一致；另验算超大屏的预览内存预算。
- 最终 31 项真机检查全部通过，8.927 秒。日志（`artifacts/audit-2.0.10/regressions.log`）。首次新增回归确实复现二次断行；初次修复中的余量导致按字数少一字，已修正后重新运行完整相关检查，不把先前失败的运行计为通过。
- 该像素检查验证 SDR 可见区域；不把屏幕截图当作 HDR 亮度验证，也未重跑完整 50 MP / 百张批量验收。
