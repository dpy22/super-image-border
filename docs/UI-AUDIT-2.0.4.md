# 2.0.4 界面与交互审查

2026-10-27。范围：原生安卓从选择照片、正文/参数/水印编辑到导出及作品库。依据本轮 Redmi Android 16 实际截图、控件树和代码；不是仅依据历史截图。目标：照片为主、玻璃导航、清楚的文字动作、稳定的输入、可恢复的操作。

规范：[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)、[Android 触控与语义](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)。Android 自有玻璃实现，非 Apple 原生组件；玻璃用于控制层，图片内容保持清晰。触控区域至少 48 dp。

| 16 | 导出：整体比例高度再叠加标题，批量按钮被系统底栏遮挡 | 单一高度预算、滚动设置、固定动作区与底部安全区 | 已优化 |
| 17 | 导出：尺寸少单位、格式摘要层级零散 | 输出尺寸含 px，编码摘要保持简短、切图明确 | 已优化 |

| 20 | 作品库：删除草稿/预设不可恢复却直接执行 | 删除前明确对象和影响；移除照片仍用撤销，无额外确认 | 已优化 |
| 21 | 全局：选项仅颜色反馈、短标签可能挤压大字体 | 选中语义、横向可达、深浅色与 1.5 倍字体检查 | 已优化 |
| 22 | 全局：说明文案和动作命名 | 删除重复说明；仅在权限、模式变化、失败时说明必要原因 | 已优化 |

## 改版后流程与结果

1. **选择照片：正常。** 原生相册共用玻璃导航材质，状态栏图标可读；多选按顺序编号，清空立即归零、添加禁用，取消保留正在编辑的作品。本次仅使用四张自建色块测试图。长列表完整滚动和所有授权变化分支尚未逐项真机遍历。
2. **摄影参数：正常。** 标签独立，输入/勾选/清空/恢复同排居中，两个动作各 48 dp；连续 abc 输入保持焦点且位置不跳动。正式精简包读取当前照片安全标签 51 项，与原文件独立读取结果一致。
3. **正文：正常。** 新建和缺失字段统一段间距 .5 字高，行距 1.3；显式保存的 0 保留。顶部恢复默认只恢复文字样式，正文和调色不变，真机测试通过。
4. **水印与调色：正常。** 取消选择改为文字，样式保持一行文字按钮；无选中图层时收紧面板。调色独立恢复、不清除正文，测试通过。
5. **导出：正常。** 最终包补足底部 24 dp 留白，两个保存动作完整显示在手势区域上方。设置滚动、保存固定；含框尺寸带 px。
6. **作品库：正常。** 草稿优先，新建操作常显，预设管理集中到更多，完成可直接关闭，空分组隐藏。永久删除前显示确认，已导出图片保留；确认代码已审查，本轮未实际删除用户草稿。
